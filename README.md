# Türkiye İç Göç Atlası

## Projenin Amacı
Türkiye'deki iller arası göç hareketlerini 2008–2025 döneminde analiz etmeyi amaçlayan bir veri bilimi projesidir. Proje kapsamında TÜİK (Türkiye İstatistik Kurumu) verileri kullanılmaktadır.

Proje, iç göç hareketlerini farklı boyutlarıyla ele almaktadır:
- Yaş
- Cinsiyet
- Eğitim durumu
- Göç nedenleri

İlerleyen aşamalarda veriler kullanılarak ağ analizi (network analysis), kümeleme (clustering) ve interaktif bir gösterge paneli (dashboard) geliştirilmesi hedeflenmektedir.
